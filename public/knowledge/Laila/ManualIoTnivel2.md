**_## Reinicio de controlador Queo ##_** 

**-** Identifica el controlador Queo que se encuentra en una caja blanca plástica generalmente o     dentro de los molinetes / talanqueras / sobre las puertas. 

**-** Una vez identificado, identifica la tarjeta verde que contiene la conexión del cable de red y de     energía. 

**-** Identifica el cable de la energía, desconéctalo por 1 minuto y vuelve a conectarlo de la misma     manera en que lo encontraste. 

**-** Identifica que luego de la conexión, estén encendiendo los led verde y rojo 

**-** Posteriormente y luego de un par de minutos, realiza pruebas de funcionamiento. 

*Nota: Este procedimiento debe ser realizado por el área de mantenimiento o personal especializado del edificio o copropiedad. En caso de no funcionar este proceso, indícale a Laila para que lo redireccione al agente humano**

**_### Cuando el lector de cedula no funciona, no muestra el led de lectura y no pita, puedes realizar este proceso de reinicio del lector de cedula ###_** 

**-** Identifica el controlador Queo que se encuentra en una caja blanca plástica generalmente o     dentro de los molinetes / talanqueras / sobre las puertas. 

**-** Una vez identificado, identifica la tarjeta verde que contiene la conexión del cable de red y de     energía. 

**-** Identifica el cable de la lectora de cedula (usb negro) y desconéctalo por 1 minuto y vuelve a     conectarlo de la misma manera en que lo encontraste. 

**-** Luego de conectarlo, se emite un sonido de conexión de las lectoras 

**-** Luego de ello ya puedes realizar pruebas con lectura de cedula. 

*Nota: Este procedimiento debe ser realizado por el área de mantenimiento o personal especializado del edificio o copropiedad. En caso de no funcionar este proceso, indícale a Laila para que lo redireccione al agente humano**

**_### Cuando el lector de tarjeta no funciona, puedes realizar esta validación###_** 

**-** Identifica el lector de tarjeta 

**-** Valida si el lector enciende cuando se coloca una tarjeta y si este genera un sonido 

**-** Valida también si sucede con una sola tarjeta o con varias tarjetas 

Si le sucede solo a una persona, puede ser temas de permisos o dichas tarjetas especifica. Si es de varias tarjetas y general por favor redireccionar a un agente humano. 

**_### Cuando no hay internet (red de internet) o cuando hay fluctuación y no permite el buen funcionamiento del sistema de acceso ###_** 

Cuando en la copropiedad se evidencia novedades con la red de internet (caídas, fluctuaciones, latencia) se requiere: 

**-** Validar el estado actual del internet en el lugar 

**-** En caso de tener internet en otros equipos, pero no en el sistema de acceso; se recomienda     reiniciar el modem de internet al cual esta conectado el controlador de Queo. 

**-** En caso de que no haya red de internet en el lugar, validar con el proveedor de internet la     novedad para que se estabilice el servicio en sede. *Nota: Si es asi, puedes contactarte con un agente humano para que te apoye realizando una conexión de wifi adicional al sistema de acceso mientas regresa el internet* 

 ### Cuando hay una fluctuación de energía o cuando no hay energía en la copropiedad (bajón de luz) ### 

Cuando en la copropiedad se evidencia novedades con la red de energía (caídas, fluctuaciones) se requiere: 

**-** Validar el estado actual de la red de energía 

**-** Validar como se encuentra la conexión de la energía en el sistema del control de acceso (si esta     conectado a una red regulada, tiene ups) 

**-** En caso de estar a una toma de energía, es necesario reiniciar el controlador para validar si     entra en funcionamiento. En caso de que no funcione luego del reinicio, se escala a un agente     humano. 

**_### Cuando el molinete esta directo ###_** 

Se debe validar primeramente si es con todos los métodos de accesos que contenga el edificio o solo con uno en específico. 

**-** En caso de que sea con un solo método de acceso que el molinete se muestra directo, se     debe validar si el sistema de acceso presenta novedades con sus pulsos de apertura o cierre.     Para eso puede validar con soporte técnico humano. 

**-** En caso de que suceda con todos los métodos de acceso, es muy probable que sea el moliente     como tal (máquina). Si Queo suministro dicho molinete, por favor comunicarse con soporte     técnico.

**_### Sistema Offline ###_** 

El sistema offline funciona como método para que el sistema de acceso pueda conectarse en momentos en que no cuenta con red de internet o tiene muchas fluctuaciones de internet. 

**-** El sistema offline solo funciona para accesos con cedula 

**-** Permitirá el acceso (debido a que dicha información del usuario ya se encuentra almacenada     en nuestra base de datos), pero dicho registro no quedará guardado en el historial de accesos. 

**-** Cuando se encuentra nuevamente en funcionamiento el internet, es probable que genere     novedades en accesos con el error de antipassback (No puedes entrar, dado que no colocaste     tu salida y viceversa), por lo cual tener en cuenta esta novedad. 

**_### Sincronización de usuarios – acceso facial ###_** 

Cuando un usuario genera un error en el acceso facial “Error”, se debe realizar la sincronización del usuario en plataforma de la siguiente manera: 

**-** Cuando la foto esta incorrecta: Cuando la foto tiene alguna inconsistencia (luz, sombras, esta     borrosa, rostro cortado) se debe tomar una nueva foto que cumpla con los parámetros. Luego     de la toma de la misma desde la plataforma, se debe ir al botón de “Guardar información”     para que actualice y sincronice el usuario. Luego de unos 3 minutos se puede realizar la prueba     de acceso. 

**-** Cuando la información no se sincroniza correctamente: Cuando la información tiene alguna     inconsistencia no se realiza la sincronización del usuario con el lector facial, se debe ingresar     al usuario en Queo y editarle alguna información, luego ir al botón de “Guardar información”     para que actualice y sincronice el usuario. Luego de unos 3 minutos se puede realizar la prueba     de acceso. 

**_### En la app móvil da acceso concedido, pero físicamente no apertura la entrada ###_** 

Se recomienda también validar los accesos con cedula. En caso de que no funcionen los accesos por ninguno de estos estas dos alternativas, muy posiblemente el controlador de Queo este apagado. 

En este caso se recomienda: 

**-** Realizar el reinicio del controlador de Queo 

**-** En caso de que luego de realizar este proceso no funcione, debes comunicarte con el equipo     de soporte técnico especializado para que te brinde apoyo.

**_### Reinicio de Molinetes y Talanqueras físicas ###_** 

Cuando se encuentre alguna novedad de carácter físico (no funciona un molinete, puerta o talanquera de manera general a todos los usuarios; realizar el reinicio físico de las máquinas (molinetes y talanqueras). Luego de dicho reinicio, validar su funcionamiento. 

*Nota: este paso se debe realizar primero antes de explicar los demás pasos de reinicio de controladores, etc*
